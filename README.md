# AndroidStudio--SpaceRace

This is a simple Android Game inspired by ancient videogames, developed in Java using the LibGDX library.

A user can:

- Move the spacecraft
- Fire a laser
- Get hit by an asteroid
- Pause the game
- Capture coins and earn points
